🎬 Cinema Audience Booking Analytics using SQL and Power BI

## 📌 1. Project Overview
This project analyzes movie theatre ticket sales, revenue, ticket pricing, and occupancy using SQL Server and Power BI. The objective is to evaluate film and cinema performance, identify occupancy patterns, and generate actionable business insights to support data-driven decision-making.

## 🎯 2. Business Problem
Movie theatres need to understand how films, cinemas, ticket prices, and showtimes influence revenue and seat occupancy.

This project addresses the following business questions:
- Which films generate the highest revenue?
- Which cinemas perform best?
- How does revenue change over time?
- Which showtime codes have higher or lower occupancy?
- What is the relationship between ticket prices and occupancy?
- How can cinema performance be improved?

## 🎯 3. Project Objectives
- Analyze overall theatre revenue and ticket sales.
- Identify top-performing films and cinemas.
- Evaluate monthly and quarterly revenue trends.
- Analyze occupancy and ticket pricing patterns.
- Build an interactive Power BI dashboard.
- Generate meaningful business insights and recommendations.

## 🛠️ 4. Tools & Technologies
- **SQL Server:** Data profiling, cleaning, validation, querying and analysis.
- **SQL:** Joins, aggregations, subqueries, CTEs and views.
- **Power BI:** Interactive dashboard development and visualization.
- **Power Query:** Data transformation and preparation.
- **DAX:** KPI calculations and measures.

## 📂 5. Dataset Information
- **Dataset:** Cinema Audience Forecasting Challenge
- **Source:** Kaggle
- **Original Records:** 142,524
- **Cleaned Records:** 142,418
- **Date Range:** 21 February 2018 – 4 November 2018
- **Key Columns:** Film Code, Cinema Code, Total Sales, Tickets Sold, Ticket Price, Occupancy, Showtime, Capacity and Date.
